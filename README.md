# Particle Shapes Project

Interactive 3D particle shapes project built with Three.js. Features smooth morphing transitions between Sphere, Cube, Pyramid, and Torus shapes, camera zoom, and click-triggered burst effects for a dynamic visual experience.

## Project Structure
```
particle_shapes_project/
├── index.html
├── main.js
├── shapes.js
├── morph.js
└── burst.js
```

## How to Run
1. Open `index.html` in a web browser.
2. Click and drag to rotate the shapes.
3. Use mouse wheel to zoom in/out.
4. Click on the shapes to trigger a burst effect.
5. Press the "Change Shape" button to morph between different shapes.

## Features
- Sphere, Cube, Pyramid, and Torus particle shapes
- Smooth morphing transitions
- Interactive burst effect on click
- Camera zoom and rotation
- Dynamic color animation

## Dependencies
- [Three.js r134](https://cdnjs.cloudflare.com/ajax/libs/three.js/r134/three.min.js)
